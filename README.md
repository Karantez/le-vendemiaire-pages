## Contenu du dépôt

| Fichier | Contenu |
|---|---|
| `index.html` | Accueil et liens vers les deux documents |
| `terms.html` | Conditions d’utilisation |
| `privacy.html` | Politique de confidentialité |
| `style.css` | Présentation commune |
| `.nojekyll` | Publication des fichiers statiques sans Jekyll |

GitHub Pages publie la branche `main`, depuis la racine du dépôt. Les pages fonctionnent sans script ni dépendance externe.

Ce dépôt contient uniquement les pages d’information. Le code du bot, sa configuration, sa base et ses sauvegardes restent séparés.
